# Cesanese — Vigne, territori, persone

V2 del prototipo statico per GitHub Pages.

## Struttura
- `index.html` — homepage e sezioni
- `style.css` — identità visiva responsive
- `app.js` — ricerca e filtri delle cantine
- `data.js` — database delle 88 cantine/produttori della V1
- `.nojekyll` — pubblicazione diretta dei file statici

## V2
La homepage è stata riprogettata in chiave contemporanea e minimal, con il paesaggio viticolo come elemento hero. L'immagine attuale è una **immagine di prova esterna** indicata durante la progettazione; prima della pubblicazione definitiva va sostituita con una fotografia di cui siano verificati fonte e diritti d'uso.

Le informazioni non verificate nel database restano esplicitamente indicate come tali.
